# Render

Managed hosting for web services, static sites, cron jobs
and databases, driven from a connected Git repository.

## What it is good at

- Predictability. Build, deploy, logs and rollback behave
  the way you expect with no surprises.
- Free static site hosting, and managed PostgreSQL when
  you need it.
- Preview environments per pull request — see
  [[Deployment Environments]].

## Watch out for

- Free-tier web services sleep when idle; a cold start is
  a bounced visitor on a marketing page.
- Managed database pricing is the line that grows.
- As with any PaaS, three services at $7 each has quietly
  become more than a VPS running all three.
