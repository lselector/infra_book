# OWASP

The Open Worldwide Application Security Project: a
nonprofit publishing free, vendor-neutral application
security material.

## What to actually use

- **[[OWASP Top 10]]** — the awareness list; a pre-launch
  checklist.
- **ASVS** — the Application Security Verification
  Standard, a levelled list of requirements. Useful as the
  basis of a security spec.
- **WSTG** — the Web Security Testing Guide, procedures
  for testing each area. This is what a
  [[Security Testing]] pass follows.
- **Cheat Sheet Series** — short, concrete guidance per
  topic. The most immediately useful of the four.
- **[[OWASP ZAP]]** — the scanner.

## Why it matters here

It is the reference the whole industry cites, it is free,
and it is specific enough to act on. When a security
questionnaire asks what standard you follow, this is a
credible answer that costs nothing.
